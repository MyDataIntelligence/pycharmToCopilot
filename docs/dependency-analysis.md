# Dependency analysis

Python PSI/reference resolution supplies confirmed outgoing and incoming project relations. Naming and path conventions add related tests, package initializers and project configuration. Structured/text scanning adds configuration, CI/CD and Microsoft Fabric relations, including notebook run calls and pipeline activities.

Candidates retain confidence, distance, evidence and every relation. Ranking uses the highest applicable relationship score plus explicit generated/exclusion penalties. Pinned files are allocated independently before automatic sorting. Files prepared in previous batches are skipped automatically unless repinned.
